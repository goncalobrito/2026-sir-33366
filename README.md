# Atividade Prática #1 - SIR (Consumo e Implementação de APIs RESTful)

## Links de Produção
* **Frontend (Vercel):** https://2026-sir-33366-frontend.vercel.app/
* **API RESTful (Render):** https://api-escola-sir.onrender.com
* **Documentação Swagger:** https://api-escola-sir.onrender.com/api-docs

## Tecnologias Utilizadas
* **Backend:** Node.js, Express, Mongoose (Padrão MVC), Swagger JSDoc
* **Base de Dados:** MongoDB Atlas
* **Frontend:** HTML5, CSS3/Tailwind, JavaScript Vanilla (Fetch API)
* **Mock Server / Testes:** JSON-Server, Postman

## Execução Local (Backend)
1. Entrar na pasta: `cd backend`
2. Instalar dependências: `npm install`
3. Configurar `.env` com a string `MONGO_URI`
4. Iniciar: `npm run dev`
5. Aceder ao Swagger: `http://localhost:5000/api-docs`
